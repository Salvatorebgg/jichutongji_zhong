# 2026-06-04 工作日志

## 修复统计方法全部报错问题
- **问题**: 点击"加载示例"后执行任何统计方法都直接报错
- **根因**: `app.js` 的 `buildVarControls()` 函数把 `STATE.variableTypes`（分组格式 `{continuous: [...], binary: [...]}`）当成逐列格式 `{col_name: 'type'}` 来读，导致连续变量和分类变量筛选结果为空数组，所有下拉框无选项，`var` 字段始终为空
- **修复内容**:
  1. 在 `buildVarControls()` 中新增 `colTypeMap` 转换逻辑，将分组格式转为逐列查找字典
  2. 使用 `colTypeMap` 替代直接读取 `varTypes` 来筛选变量
  3. 增加候选变量为空时回退到全部列的兜底逻辑
  4. 更新 `buildSelectField()` 函数增加 `autoSelect` 参数，使关键变量自动选中第一个默认值
  5. 分组变量筛选增加 `group` 类型，受试者ID优先筛选 `id` 类型
- **验证**: 后端全部 20+ 统计方法 API 测试通过（t检验、ANOVA、卡方、相关、回归、生存分析等）

## 修复统计分析无图表可视化 + 变量选择不完善
- **问题1**: 统计分析结果只显示文字摘要和表格，没有任何Plotly图表
- **问题2**: `survival_time` 被 `classify_variables()` 分类为 `date` 类型，不纳入 `continuousCols`，导致生存分析选不到时间变量
- **问题3**: McNemar 的 `paired_var` 从 `continuousCols` 选取，但应该从 `categoricalCols` 选取
- **问题4**: `paired_var` 的 autoSelect 总是选第一个候选，可能和 `var` 重复
- **修复内容**:
  1. 新增 `renderStatChart()` 函数，为每种统计方法生成对应的 Plotly 图表：
     - t检验/ANOVA/Kruskal-Wallis/Mann-Whitney: 分组箱线图
     - 配对t检验/Wilcoxon: 配对散点图
     - 单样本t检验: 直方图+均值线
     - 正态性检验: Q-Q图
     - 卡方检验/Fisher精确检验: 堆叠条形图
     - 相关分析: 散点图+回归线
     - 生存分析: Kaplan-Meier曲线
     - 回归/判别分析: 系数柱状图
  2. `continuousCols` 筛选添加 `date` 类型支持
  3. McNemar 的 `paired_var` 根据 `config.varType === 'categorical'` 判断使用分类变量
  4. `buildSelectField()` 新增 `defaultVal` 参数，`paired_var` 默认选与 `var` 不同的变量
  5. `runAnalysis()` 中通过 `loadChartDataset()` 加载完整数据集用于图表渲染
  6. 新增 `_statPalette()` 和 `_normalInv()` 辅助函数
